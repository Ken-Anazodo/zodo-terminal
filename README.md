🚀 Zodo Terminal
Zodo Terminal is a powerful, scalable e-commerce platform designed to deliver seamless online shopping experiences. Built with Flask, JavaScript, ORM, and SQL, it ensures high performance, flexibility, and efficiency for businesses looking to grow their online presence.

✨ Features
✅ Dynamic E-Commerce System – Supports brands, categories, and product management
✅ Optimized Performance – Built with Flask and ORM for fast, efficient database operations
✅ User-Centric UI/UX – Smooth navigation and responsive design for better customer engagement
✅ Secure & Scalable – Implements best practices for security and future scalability

🔧 Tech Stack
Backend: Python, Flask, SQLAlchemy ORM, MySQL
Frontend: JavaScript, HTML, CSS, Bootstrap, Jquery AJAX, Gsap
